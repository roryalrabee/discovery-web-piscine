- In ex03, I wrote a README and set up the bonus SSH authentication. 

## Why Git Makes Development Easier

### Safety
- If I break something, I can go back to an older saved version.
- Every commit is a snapshot of my project.

### History
- With git log, I can see the history.
- Each commit shows who made the changes and when.

### Collaboration
- Without Git, two people editing the same file can cause conflicts.
- With Git, each person works separately and then they merge their changes.
